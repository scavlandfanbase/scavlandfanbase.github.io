SCAVLAND Roadmap

A look at the main improvements being made to the fan database.

In progress

  • More in-game evidenceAdding verified screenshots to item, armour, weapon and recipe records.
  • Vendor shop galleriesOrganising shop screenshots so visitors can browse what each vendor screen looks like.
  • Clearer database cardsLinking trustworthy screenshots directly from cards where available.

Coming up

  • Website layoutImproving the way information is arranged so the database is easier to browse.
  • Corrections to dataReviewing reports and evidence to correct inaccurate or incomplete entries.
  • Ongoing mobile polishKeeping the database easy to use on phones as new content is added.

How players can help

  • Share clear tooltipsFull screenshots with the exact name and visible stats are the most useful.
  • Show 100% armour durabilityThis is needed to verify normal armour resistance values.

Please only send screenshots that match these two requests. The database labels information as verified when it has direct in-game evidence. See the evidence guide for the exact screenshot format.
